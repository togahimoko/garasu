# Garasu V2 — аудит маршрутизации и статус внедрения

## Цели

Один автоматический выбор из доступных нод (без ручных селекторов), компактные нативные конфиги, отдельные провайдеры и GeoSite/GeoIP вместо инлайна десятков тысяч доменов. Обновление клиентов — каждые 21 600 секунд. Русские критические ресурсы идут DIRECT, заблокированные — через выбранную ноду, зарубежный трафик — через ноду, реклама REJECT с исключениями.

## Изменения относительно первоначального Garasu

- 37 нативных rule-providers вместо 10. Из них 35 (`domain`/`ipcidr`) компилируются в Mihomo MRS. Ещё два (`classical`) сохраняют 105 `keyword` и шесть `regexp` условий, которые MRS не способен выразить без потери смысла.
- Для sing-box все 37 наборов компилируются в SRS. Для Clash/Premium — удалённые YAML-провайдеры; Stash использует MRS и classical YAML; Shadowrocket — удалённые источники подходящего формата.
- Сохраняются категории отдельных продуктов и RU-исключений, а не только общая RU-проверка: Telegram (+IP), GitHub, Microsoft, Apple, Steam, Twitch, Epic, Origin, Riot, Faceit, Google Play, Torrent, реклама, телеметрия и др.
- Источники GeoSite взяты из MIT-лицензированного `hydraponique/roscomvpn-geosite` на **конкретном SHA**, лицензионный текст помещён в `docs/licenses/`.
- Из direct-whitelist исключены сервисы проверки внешнего IP, иначе они показывали бы домашний IP вместо VPN.
- Семь зарубежных категорий (Microsoft, Apple, Google Play, Twitch, Pinterest, торрент-домены, Push) больше не идут DIRECT: направлены в автоматическую группу Garasu во всех пяти настольных/мобильных маршрутизаторах. Российские ru-services/ru-whitelist остаются DIRECT.
- URL провайдеров не зависят от VPN-группы при первом запуске. В Mihomo `proxy: DIRECT`, в sing-box отдельный direct HTTP client.
- Сохранены пять типов ответов и правило для отдельных приложений в одном наборе `release/remnawave/srr.json`.

## Проверенные свойства

- Python unit/regression suite: 139 тестов после интеграции актуального main.
- Нативная проверка Mihomo с 0/1/2/5 синтетическими нодами, с полноценными локальными правилами; отдельный проверочный трафик DIRECT/PROXY/REJECT.
- Воспроизводимость 37/37 MRS (SHA256), компиляция 37/37 SRS, native sing-box 1.14 schema check + запуск реального процесса, Clash YAML проверен Mihomo-парсером с 1/2/5 нодами.
- Отдельный реальный VLESS/Reality-узел с Mac: синтаксис проходит, все **37/37** MRS/YAML провайдеров загружаются с локального HTTP-сервера после исправления очереди входящих соединений тестового сервера, но HTTPS-трафик через настоящий узел завершается ошибкой подключения.
- Не было переключения действующего Clash Verge, изменения системного прокси, TUN, или личной ноды. Тестовые файлы с личными узлами временные и автоматически удаляются.

## Ограничения, не выдавать за готовность

- Изолированный холодный старт с публичной ветки `feat/garasu-v2-full-coverage`: Mihomo успешно скачал 35/35 MRS и 2/2 classical YAML, sing-box успешно скачал 37/37 SRS без работающей VPN-ноды. Это подтверждает доступность с данного Mac, но не из каждой сети России.
- Проблема реального исходящего VLESS/Reality-туннеля не закрыта. Пока он не проходит HTTPS-тест, запрещён автоматический переход с рабочей конфигурации.
- Наличие `interval: 21600` **не гарантирует**, что источники действительно обновляются в GitHub. Для `scripts/update_six_hourly.sh` нужен запущенный Mac и авторизованный Git push. Если нет авторизации — публикация не происходит.
- Native Stash, оригинальный Clash Premium и Shadowrocket на настоящих устройствах не проверены. Тестовый Mihomo парсер — лишь проверка совместимости синтаксиса.
- `telegram-ips` первоначально получен через **неофициальный** публичный mirror, поскольку `core.telegram.org` недоступен из текущей сети. Фактический источник и SHA256 занесены в `rules/extra/provenance.json`; официальный источник при доступности имеет приоритет.
- Не следует заменять действующий профиль до успешного теста нод, загрузки наборов и DNS/разделения трафика.
