# Garasu — проверка бинарных GeoSite и GeoIP

Бинарные форматы V2Ray декодированы, сравнение категорий выполняется
**с содержимым исходных списков**, не только с SHA-256.

| Проверка | Результат |
| --- | ---: |
| GeoSite категорий | 38 |
| GeoIP категорий | 5 |
| BANNED-RU полностью совпадает с rules/rkn-domains.list | 75306 |
| BLOCKED-RU совпадает с rules/rkn-ips.cidr | 25391 |
| RU совпадает с rules/ru-ips.cidr | 25157 |
| CATEGORY-GEOBLOCK-RU | 21989 |
| GARASU-ADS | 1107 |
| Текстовый ads | 1221 |
| В бинарном, отсутствуют в текстовом ads | 5 |
| В текстовом, отсутствуют в бинарном ads | 119 |

Все категории, на которые ссылаются INCY, Happ и Xray-шаблоны,
**физически присутствуют** в соответствующих .dat.

Разные ads-наборы могут быть результатом намеренной очистки пересечений;
перед унификацией надо проверить целевую политику блокировки.

Бинарный GeoSite 2217740 байт, GeoIP 1049786 байт. Размер на диске не равен памяти
клиентского сетевого расширения; для iOS необходим нативный тест.

Машинный отчёт: [geodata-integrity.json](geodata-integrity.json).
