# Garasu — единая маршрутизация для пользователей РФ

**Одна политика Garasu, одна подписка Remnawave, разные нативные форматы.** Архитектурный ориентир — RoscomVPN Routing. Его файлы и правила не копируются: используются ранее закреплённые исходники Garasu и собственная сборка. Отдельных профилей Lite/Full нет.

Канонический источник: [policy/universal.json](../policy/universal.json); генератор: [scripts/sync_universal_routing.py](../scripts/sync_universal_routing.py).

## Приоритеты

| Приоритет | Трафик | Действие |
| --- | --- | --- |
| 1 | LAN, localhost и приватные IPv4/IPv6 | DIRECT |
| 2 | Рекламные/телеметрические домены без четырёх явно разрешённых бизнес-API | REJECT |
| 3 | Заблокированные российские домены / IP, категории YouTube/Discord/AI/crypto/proxy | VPN |
| 4 | 17 критичных российских доменных зон, 10 российских TLD и российские IP | DIRECT |
| 5 | Все остальные адреса, включая зарубежные | VPN |

Роутинг не меняет маршруты серверов: VPN-ноды и разрешения на них вводит Remnawave. В Mihomo видна одна группа **Garasu**, в ней автоматически проверяемый **Garasu Auto** и ручные персональные ноды. При отсутствии VPN-узлов зарубежные адреса не должны переходить в DIRECT.

## Автономность списка блокировок

В Mihomo, Stash, Shadowrocket и sing-box встроены необходимые для российского DIRECT исключения из **21 937 доменов РКН**, **25 391 заблокированного IP CIDR** и **25 157 российских IP CIDR**. Это отфильтрованная нужная для ROUTING часть исходного каталога из 75 306 записей; остальные зарубежные заблокированные домены в любом случае уходят в VPN по маршруту по умолчанию.

- Mihomo/Stash: внутренние inline rule-provider'ы; первые совпадения РКН идут раньше широкого RU DIRECT.
- Shadowrocket: реальные нативные inline-правила, без HTTP rule-set bootstrap.
- sing-box 1.14: нативные inline rule-set и последняя ветка `→ Remnawave`.
- INCY/Happ: согласованные пары Garasu `geosite.dat`/`geoip.dat` по URL. До получения файлов категории RU DIRECT не гарантированы; требуется реальный импорт и проверка клиентского механизма обновления.
- Xray JSON: категории из Garasu `geosite.dat`/`geoip.dat`, которые необходимо установить вместе с Xray, не рассчитывая на стандартную geodata.

**Доставка актуальных данных**: правила для desktop-клиентов встраиваются в подписку при сборке; их обновление требует новой выдачи шаблона Remnawave. Это устраняет первый сетевой bootstrap для rule-provider'ов, но не делает обновления GitHub автоматически видимыми внутри панели. Для INCY используется `autorouting` с URL и отдельное обновление geo. Для Happ в SRR генерируется `routing` заголовок с base64 профилем и повышенным `LastUpdated`; рекламные правила представлены компактной `geosite:garasu-ads` в нашем бинарном GeoSite. Заголовок не должен превышать 3,5 КБ, иначе стандартный Nginx с небольшим proxy_buffer_size может вернуть 502.

Четыре узких исключения из рекламного списка защищают API сервисов Ozon/Wildberries: `xapi.ozon.ru`, `advert-api.wildberries.ru`, `advert-media-api.wildberries.ru`, `analytics.wildberries.ru`. Остальные записи рекламы продолжают блокироваться; полная корректность приложений требует ручных и сетевых тестов.

## Проверки

- Офлайн-качество: 110/110 unit/regression PASS (после обновления компактного Happ), хеши 13/13 MRS, сверка GeoSite/GeoIP и манифеста, генератор семи профилей и сканирование секретов.
- Нативный Mihomo на Mac: конфигурации с 0, 1, 2 и 5 синтетическими нодами проходят `-t`.
- Локальный end-to-end Mihomo c подменёнными HTTP/SOCKS5: `sberbank.ru` → DIRECT; неизвестный `.net` → PROXY; заблокированный `003.su` → PROXY; реклама → REJECT.
- SRR Happ включает обновлённую base64 конфигурацию из `release/happ/config.json`; типы выдачи Remnawave и пользовательские ноды не изменены.

**Не подтверждено и требует проверки перед массовым rollout:** полноценный импорт в настоящие Stash/Shadowrocket/sing-box/INCY/Happ/Xray, работа DNS/UDP/TUN и переключения узлов на сетях РФ, реальная выдача Remnawave и живые подключения. Большие inline-профили увеличивают размер подписки; на мобильных клиентах нужна проверка ограничений расширения.

## Контроль

```bash
python3 scripts/sync_universal_routing.py --check
python3 scripts/qa.py --branch main --core /path/to/mihomo
```

Запуск локального QA не переключает VPN. При изменении исходных блоклистов обязательно перегенерировать все семь native-профилей и Happ SRR, перепроверить cross-client parity, размеры и доменные пересечения. До тестирования живого Remnawave изменения в панели не применять.
