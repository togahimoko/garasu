# Безопасность Garasu

## Секреты и публикации

Не публикуйте токены Remnawave, личные subscription URL, UUID пользователей, ключи REALITY, SSH-ключи, дампы баз данных, рабочие .env или логи с чувствительными данными.

Если секрет попал в историю Git, **сначала отзовите или замените его** у владельца. Удаление строки из последнего коммита не удаляет прежние версии.

## Сообщение об уязвимости

Не размещайте действующие секреты и подробности эксплуатации в публичных Issues. Если для репозитория доступно GitHub Private vulnerability reporting, используйте его; иначе свяжитесь с владельцем приватным способом.

Не тестируйте чужие VPN-узлы без разрешения.

## Контроль

```bash
python3 scripts/qa.py --branch main
```

Эта проверка не заменяет аудит приватной Remnawave-панели, сетевую диагностику или тестирование реальных клиентских приложений.
