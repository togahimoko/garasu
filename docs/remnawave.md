# Подключение Garasu к Remnawave

## Сначала проверить публичную сборку

Убедитесь, что GitHub Actions создал `install/manifest.json`, `rules/*.list`, `rules/*.cidr`, `geo/geoip.dat` и `geo/geosite.dat`. Проверьте доступность всех нужных URL из РФ и по мобильной сети. Не отключайте действующую подписку и не меняйте существующие рабочие Inbound/Outbound.

## Shadowrocket (iOS)

Персональная подписка Remnawave импортируется стандартно. Отдельная кнопка **Установить Garasu MAX** на Subscription Page должна открывать:

`shadowrocket://config/add/https://raw.githubusercontent.com/togahimoko/garasu/main/clients/shadowrocket.conf`

После установки на клиенте активировать этот Config и Global Routing = Config; включить автообновление удалённой конфигурации. Серверы берутся **из личной подписки**, а маршрутизация из Garasu.

## INCY

Добавить в страницу подписки кнопку:

`incy://autorouting/onadd/https://raw.githubusercontent.com/togahimoko/garasu/main/clients/incy.json`

INCY поддерживает прямую автоматическую доставку профиля вместе с персональной подпиской через HTTP-заголовок:

`autorouting: incy://autorouting/onadd/https://raw.githubusercontent.com/togahimoko/garasu/main/clients/incy.json`

Если после тестов вы подключаете ответ через Subscription Response Rules, для INCY сохраняйте стандартный **XRAY_BASE64** ответ на серверы и добавляйте только указанный короткий заголовок. Не заменяйте правила других приложений. Протестируйте на отдельном клиенте, проверьте User-Agent, HTTP 200 и импорт.

## Happ

Профиль находится в `clients/happ.json`. Официальный формат установки:

`happ://routing/onadd/<base64(JSON)>`

Сборщик автоматически публикует **готовую** ссылку с реальным Base64 в `install/links.json`; её можно добавить как кнопку Subscription Page. Для полного автоматического повторного импорта можно позже передавать это же значение в заголовке `routing` при обновлении подписки, **но только после проверки размера HTTP-заголовка, Nginx и форматирования ответа**. Не добавляйте большой заголовок глобально: это может нарушить выдачу подписок всем пользователям.

Happ может обновлять GeoIP/GeoSite по своим собственным правилам и расписанию, а обновление целого JSON-профиля происходит при повторном импорте или обновлении подписки. Не называйте это URL autorouting — Happ не использует механизм INCY.

## Clash Verge / Mihomo

Скачайте `clients/mihomo-remnawave.yaml` и установите его как Mihomo template в Remnawave. Шаблон **не является самостоятельной персональной ссылкой**: Remnawave добавляет реальные узлы пользователя при генерации его обычной Mihomo-подписки.

Перед массовым использованием проверьте тестовую подписку: корректные `proxies`, непустую группу `Garasu Auto`, доступность Rule Providers и корректный порядок RU/РКН правил.

## Remnawave Subpage Builder

В существующих карточках Shadowrocket, INCY и Happ добавьте кнопку `external` с соответствующей ссылкой из `install/links.json`. **Сохраняйте оригинальные кнопки персональных подписок.** Сначала экспортируйте Subpage Builder JSON, сохраните копию, добавьте кнопки и проверьте на одном тестовом пользователе.

## Критерии приёмки

- Все четыре клиентских формата импортируются и применяются в реальных приложениях.
- YouTube и AI проходят через VPN; доступные российские банковские сайты идут напрямую.
- Blocked-ru исключения срабатывают до общего Russian DIRECT.
- На тестовой подписке обновление серверов работает в Clash Verge, Happ, INCY и Shadowrocket.
- Ни один сбой GitHub Action не приводит к замене рабочего профиля неполным.
- После тестов можно включать доставку маршрутов в подписках Remnawave.

### Автоматическая подготовка Subpage Builder

Сохраните экспорт существующей страницы как `my-subpage.json`. Запустите `python3 scripts/patch_subpage.py my-subpage.json my-subpage-garasu.json`. Создастся **новый** JSON с кнопками Garasu без удаления оригинальных кнопок подключения серверов. Импортировать обратно только после теста в Remnawave.
