# Garasu — единая маршрутизация (кандидат для выпуска)

**Один профиль и одна политика для всех клиентов. Никаких Lite / Full.**

Канонический источник: [policy/universal.json](../policy/universal.json).
Детерминированный генератор: [scripts/sync_universal_routing.py](../scripts/sync_universal_routing.py).

## Фактическая схема

| Приоритет | Правило | Результат |
| --- | --- | --- |
| 1 | Локальная сеть, localhost, .arpa, приватные IPv4/IPv6 | DIRECT |
| 2 | 1 221 домен из ads.list | REJECT |
| 3 | 17 проверенных корневых доменов российских банков, госуслуг и сервисов с поддоменами | DIRECT |
| 4 | **Любой другой адрес**, включая все остальные .ru и зарубежные сайты | PROXY через Garasu |

**Нет обхода через DIRECT при пропаже VPN.** Клиент вправе сообщить об ошибке соединения, но не должен переключать весь трафик в DIRECT. В Mihomo видима одна группа Garasu с автоматическим и ручным выбором разрешённых нод Remnawave.

Этот подход намеренно **не** использует широкий RU DIRECT. Часть российских сервисов, не вошедших в 17 закреплённых категорий, получит зарубежный IP VPN и может отклонить соединение. Перед продажей список обязательных DIRECT-сервисов следует расширять на основании воспроизводимых проверок и без пересечений с блокировкой РКН.

## Отсутствие зависимости от GitHub Raw при запуске

Обязательные правила встраиваются в пользовательский профиль. Mihomo и Stash используют единственный inline provider для рекламы, Shadowrocket — inline DOMAIN-SUFFIX, sing-box — inline rule-set, INCY/Happ и Xray — встроенные списки.

В каталоге [rules](../rules/) сохраняются исходные тематические наборы; MRS и GeoSite/GeoIP остаются проверенными артефактами для будущих сценариев и совместимых ссылок, **но не загружаются** в новый клиентский universal-профиль.

Таким образом, приложение не должно зависеть от успешной загрузки 13 удалённых rule-provider'ов для первоначального старта. Однако самой **первой подписке** по-прежнему требуется доступ к Remnawave, а VPN-нода должна быть доступна по сети.

## Проверенные свойства

- 104/104 локальных Python теста пройдены на момент подготовки кандидата.
- Нативный Mihomo проверен в изолированном каталоге с 0, 1, 2 и 5 синтетическими нодами.
- Полный E2E-тест Mihomo с локальным HTTP-сервером и локальным SOCKS5 подтвердил DIRECT для sberbank.ru, PROXY для неизвестного .ru и REJECT для домена рекламного набора.
- Проверено наличие одного файла политики, семи сгенерированных клиентских профилей и сохранность точек вставки пользовательских нод.
- Правила ссылаются на встроенные данные, нет зависимости от GitHub Raw в маршруте.

**Не подтверждено:** реальный импорт в Stash/Shadowrocket/INCY/Happ/sing-box/Xray, взаимодействие с действующим Remnawave SSR, доступность VPN на российских провайдерах, работоспособность всех банковских приложений, разные режимы DNS на iOS/Android. До окончания этих проверок нельзя называть клиентский rollout готовым к массовой продаже.

## Контроль перед публикацией

```bash
python3 scripts/sync_universal_routing.py --check
python3 scripts/qa.py --branch main --core /path/to/mihomo
```

Выпуск должен проходить из dev в main только после проверки, что исправления не нарушают действующие подписки. Коммит в GitHub сам по себе **не обновляет Remnawave**. Действующий main остаётся стабильной конфигурацией, пока релиз-кандидат не принят.
