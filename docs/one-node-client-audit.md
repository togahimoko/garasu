# Архивный документ

Предыдущая версия аудита была составлена с ошибочным ограничением количества нод.

**Актуальная архитектура:** [многонодовая маршрутизация, отказоустойчивость и проверки](multi-node-reliability.md).

Количество нод не фиксировано. Возможен автоматический выбор и переключение в тех клиентах, которые это поддерживают; правило маршрутизации не зависит от страны узла.

Технические сведения из этого документа перенесены в актуальные разделы аудита и тесты.
